在微信upload时提示是0s

原因

  1. GPAC 输出的这个 MP4，moov盒子（存放时长、轨道索引的元数据）放在文件末尾。
  2. 微信的解析器只读取文件开头一小段，不会扫描整个文件去找末尾的 moov；读不到时长元数据，直接判定为 0 秒，无法正常发送 / 上传。
  3. 另外文件品牌标记 compatible_brands: iso6dsmsmsixdash，这是 DASH 分片兼容标记，普通 MP4 解析器对这种组合兼容性差，加重识别异常。

本地播放器完整扫描整个文件可以播放；微信只读文件头部，拿不到时长信息 → 0 秒。

解决办法

修复命令（FFmpeg，无损封装，不重新编码，速度快）

1

ffmpeg -i b.mp4 -c copy -movflags +faststart bfix.mp4

3用JPG和MP3合成mp4

ffmpeg -y -loop 1 -i yarn.jpg -i yarn.mp3 -filter:v "scale=trunc(iw/2)*2:trunc(ih/2)*2" -c:v libx264 -tune stillimage -c:a aac -b:a 192k -pix_fmt yuv420p -shortest output.mp4
