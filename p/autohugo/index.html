利用SSH登录vps的流程

客户端向vps发起一个登录请求
    vps生成一串随机数，利用之前配置好的公钥(authorized_keys)进行加密，将加密后字符串传给客户端
    客户端利用私钥(id_rsa)进行解密，将解密后的字符串外加一些别的(sessionKey之类的、我也不知道是啥)字符串；将整合得到的新的“摘要”用私钥加密，发给vps
    vps对“摘要”用公钥解密，通过解密得到的文本判断是否认证该客户端登录

可以看到整个过程充分利用了公钥和私钥可以互相加密与解密的特点，通常说公钥加密、私钥解密

本地创建ssh

RSA4096 ssh-keygen -t rsa -b 4096 -C "add164@gmail.com"

ed25519 ssh-keygen -t ed25519 -C "ne@x.com" 查看fingerprint ssh-keygen -l -f .\id_ed25519

在C:\Users\Administrator\.ssh生成private和public key

github添加key

在github setting里添加ssh公钥

本地验证

SSH -T git@github.com

git ssh验证出现/d/SPB_Data/.ssh 不存在

生成public key的默认目录为D:\SPB_Data是什么原因， 这是因为SPB软件会生成$home system variable,需要删除home variable

3:部署流水线CICD

持续集成（Continuous Integration）、持续交付（Continuous Delivery） 、持续部署（Continuous Deployment）

在 GitHub 上创建一个新的仓库,

权限建议设置为“Private”.它将被用来用于存放 Hugo 的源文件，自定义的仓库名为“Hugo”

token生成

前往github的 Settings/Developer Settings/Personal access tokens , 点击 “Generate new token (classic)” 创建一个 token. “Expiration” 为 token 过期时间，可自定义。记得选择下方的 “repo” 和 “workflow” 选项。

==生成的token prefix == ghp_RW

配置Token

前往本仓库的 Settings/Secrets and variables/Actions 将生成的 Token 保存在仓库的环境变量中。 【这个名字很重要，在后面配置中会用】

name: deploy

# 代码提交到main分支时触发GitHub action
on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
        - name: Checkout
          uses: actions/checkout@v4
          with:
              fetch-depth: 0

        - name: Setup Hugo
          uses: peaceiris/actions-hugo@v3
          with:
              hugo-version: "latest"
              extended: true

        - name: Build Web
          run: hugo -D

        - name: Deploy Web
          uses: peaceiris/actions-gh-pages@v4
          with:
              PERSONAL_TOKEN: ${{ secrets.token的名字 }}
              EXTERNAL_REPOSITORY: hea/hea.github.io
              PUBLISH_BRANCH: main
              PUBLISH_DIR: ./public
              commit_message: auto deploy
